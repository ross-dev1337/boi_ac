# AssaultCube v1.3.0.2 Cheat

A game modification and reverse-engineering project for AssaultCube v1.3.0.2, developed for educational purposes and to explore game internals, memory structures, and debugging techniques.

## 🛠️ Tools Used

- **VSCode** — Code editing
- **IDA** — Reverse engineering
- **Cheat Engine** — Memory analysis
- **ReClass** — Memory structure analysis

## 🎯 Project Goals

- Explore the internal workings of AssaultCube v1.3.0.2.
- Learn reverse engineering and memory analysis.
- Investigate game data structures and memory layouts.
- Develop and test game modifications in a controlled environment.
