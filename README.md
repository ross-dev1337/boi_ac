# Sauerbraten x64 bit Cheat

A game modification and reverse-engineering project for Sauerbraten x64, developed for educational purposes and to explore game internals, memory structures, and debugging techniques.

## 🛠️ Tools Used

- **VSCode** — Code editing
- **IDA** — Reverse engineering
- **Cheat Engine** — Memory analysis
- **ReClass** — Memory structure analysis

## 🎯 Project Goals

- Explore the internal workings of Sauerbraten x64.
- Learn reverse engineering and memory analysis.
- Investigate game data structures and memory layouts.
- Develop and test game modifications in a controlled environment.
